# Claude Usage Widget

Claude Code 구독 사용량(5시간 세션 / 주간 한도)을 데스크톱에 상시 표시하는 Windows 11 트레이 + 플로팅 위젯.

`/usage` 를 치러 Claude Code로 돌아갈 필요 없이, 화면 구석에서 남은 한도와 리셋까지 남은 시간을 확인합니다.

```
성훈  [Max 20x]                    ⚙ – ✕
세션 (5시간)                          9%
▬▬▭▭▭▭▭▭▭▭   2시간 11분 후 리셋
주간 (7일)                           27%
▬▬▬▬▭▭▭▭▭▭   2일 9시간 후 리셋
주간 (Fable) ●                       29%
▬▬▬▬▭▭▭▭▭▭   2일 9시간 후 리셋
[24시간 추이 차트]
Opus 5 · max · thinking
```

## 기능

- **인증 재사용** — PC에 이미 로그인된 Claude Code의 자격증명을 읽기 전용으로 사용. 별도 로그인이 없습니다
- **상시 표시** — 프레임리스 · always-on-top · 작업 표시줄 미표시. 작업 영역 우측 하단에 자동 배치
- **게이지별 리셋 안내** — 남은 시간에 따라 "9분 후 리셋" / "2일 9시간 후 리셋" 처럼 단위가 바뀝니다
- **현재 세션 정보** — 계정·플랜, 사용 중인 모델·effort·thinking 상태
- **트레이 상주** — 사용률 구간에 따라 아이콘 색이 바뀌고, 마우스를 올리면 요약이 뜹니다
- **임계값 알림** — 80% / 95% 도달 시 Windows 토스트 (같은 주기에 1회만)
- **히스토리** — 스냅샷을 로컬 SQLite에 90일 보관, 24시간 추이 차트
- **색상 커스터마이즈** — 글자·게이지·배경 색과 불투명도를 설정에서 변경

## 설치

`Claude Usage Widget_0.1.0_x64-setup.exe` 를 실행합니다. 현재 사용자 계정에만 설치되므로 관리자 권한이 필요 없습니다.

**전제 조건**
- Windows 11 (Windows 10 22H2는 베스트 에포트)
- Claude Code가 설치되어 있고 **로그인된 상태** — 이 앱은 자체 로그인을 하지 않습니다
- WebView2 런타임 (Windows 11 기본 탑재)

설치 후 트레이 아이콘은 Windows 11 기본 정책상 **오버플로(`^`) 안에 숨겨집니다.** 작업 표시줄 설정에서 고정하면 상시 보입니다.

## 사용법

| 조작 | 동작 |
|---|---|
| 위젯 드래그 | 위치 이동 |
| `⚙` | 설정 창 |
| `–` | 접기 / 펼치기 (컴팩트 ↔ 확장) |
| `✕` | 트레이로 숨기기 (앱은 계속 실행) |
| 트레이 우클릭 | 위젯 표시/숨김 · 지금 새로고침 · 설정 · 종료 |

**완전 종료는 트레이 메뉴의 "종료"** 로만 합니다. `✕` 는 숨기기입니다.

## ⚠️ 비공식 API를 사용합니다

사용량 조회는 Anthropic이 공개한 API가 아니라, **Claude Code가 내부적으로 쓰는 OAuth 엔드포인트**(`GET /api/oauth/usage`)를 사용합니다.

- Anthropic이 예고 없이 변경하거나 막을 수 있습니다. 그 경우 위젯은 크래시 대신 "조회 불가" 상태로 강등됩니다
- 엔드포인트 계약은 [docs/api-schema.md](docs/api-schema.md)에 문서화되어 있고, 변경 시 수정 범위는 `usage_client.rs` 와 `model.rs` 로 한정됩니다
- 개인 용도로 만든 도구입니다. 사용 책임은 사용자에게 있습니다

## 개인정보 · 보안

- 자격증명 파일은 **읽기만** 합니다. 쓰지 않습니다
- 액세스 토큰은 Rust 경계를 넘지 않습니다. 웹뷰로 가는 것은 사용률·리셋 시각뿐입니다
- 토큰은 로그·설정·히스토리 어디에도 저장하지 않습니다 (`AccessToken` 의 `Debug` 가 값을 가리고, 테스트로 고정되어 있습니다)
- 모델·effort·thinking 정보는 Claude Code 트랜스크립트에서 **메타데이터 필드만** 읽습니다. 대화 내용은 읽지도, 보관하지도, 내보내지도 않습니다
- 사용량 데이터의 외부 전송·클라우드 동기화가 **없습니다**. usage 조회 요청 외의 네트워크 통신을 하지 않습니다

## 저장 위치

| 대상 | 경로 |
|---|---|
| 설정 | `%APPDATA%\com.psb.claude-usage-widget\settings.json` |
| 히스토리 | `%APPDATA%\com.psb.claude-usage-widget\history.db` (SQLite) |
| 자격증명(읽기 전용) | `%USERPROFILE%\.claude\.credentials.json` |

제거해도 위 설정·히스토리는 남습니다. 필요하면 직접 지우세요.

## 문제 해결

| 증상 | 원인 / 대처 |
|---|---|
| "Claude Code를 한 번 실행해 인증을 갱신해 주세요" | 토큰 만료. 이 앱은 토큰을 갱신하지 않습니다 — Claude Code를 한 번 실행하면 됩니다 |
| "N분 전 기준" 배지 | 네트워크 오류 또는 요청 제한(429). 마지막 값을 보여주는 중입니다 |
| "사용량을 가져올 수 없습니다" | 자격증명 파일이 없거나 응답 형식이 바뀌었습니다 |
| 위젯이 안 보임 | `✕` 로 숨겼을 수 있습니다. 트레이 우클릭 → "위젯 표시/숨김" |
| 차트가 "기록을 모으는 중" | 데이터가 2점 이상 쌓여야 선이 그려집니다 (기본 폴링 60초) |

## 개발

```bash
npm install
npm run tauri:dev        # 개발 (Vite HMR + Rust 자동 재빌드)
npm run check            # 타입 검사
npm run tauri:build      # 릴리스 + NSIS 인스톨러

cd src-tauri
cargo test --lib         # Rust 단위 테스트
```

기술스택과 설계 결정은 [docs/architecture.md](docs/architecture.md), 마일스톤은 [docs/tasks.md](docs/tasks.md)를 보세요.
