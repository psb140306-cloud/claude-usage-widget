### 대화 흐름

#### 1. M1 PoC — 사용량 조회 방식이 실제로 되는지부터 확인
- **AI의 반응**: 기획 단계에서 가장 큰 위험 요소로 짚었던 "비공식 사용량 조회 방법이 실제로 작동하는가"를 가장 먼저 검증했다. 설치되어 있는 Claude Code 실행 파일(v2.1.210, 240MB)에서 내부 코드를 직접 뜯어내 사용량을 조회하는 부분을 찾아냈다.
- **결과**: `GET https://api.anthropic.com/api/oauth/usage`에 특정 헤더를 붙여 요청하면 사용량 정보를 정상적으로 받아온다는 것을 확인했다(HTTP 200). Go/No-Go 판정에서 "진행(Go)"으로 결론 내고, 검증 결과를 `docs/api-schema.md`에 문서로 남겼다.

#### 2. `/bootstrap` — 기술스택 확정 및 프로젝트 뼈대 생성
- **AI의 반응**: Tauri 2.11(Rust) + Svelte 5.56(runes 문법) + Vite 8 + SQLite + uPlot(차트 라이브러리) 조합을 최종 선택했다. 창이 위젯과 설정 두 개뿐인 단순한 앱이라 SvelteKit 같은 무거운 프레임워크는 채택하지 않았다.
- **결과**: 프로젝트 폴더 구조가 갖춰졌고 빌드·테스트가 정상 동작함을 확인했다.

#### 3. M2 — 사용량 데이터를 실제로 가져오는 핵심 기능 구현
- **AI의 반응**: 자격증명 파일을 읽어 토큰을 가져오는 기능, 사용량 API를 호출하는 기능, 일정 주기로 반복 조회하는 기능 세 가지를 순서대로 만들었다. 오류가 나도 앱이 멈추지 않도록 재시도 로직도 넣었다.
- **결과**: 위젯 화면에 실제 사용량 숫자가 표시되기 시작했다. 이 시점부터 위젯이 "보여주기용 화면"에서 "실제로 쓰는 도구"로 바뀌었다.

#### 4. M3~M5 — 위젯 화면, 트레이 아이콘, 알림, 설정, 사용 이력 차트
- **AI의 반응**: 위젯에 계정·플랜 정보, 세션/주간/모델별 사용률 게이지, 24시간 추이 차트를 차례로 추가했다. 알림 임계값(80%/95%)에 도달하면 윈도우 토스트 알림을 띄우는 기능과, 색상·알림·자동 시작 등을 조정할 수 있는 설정 창도 만들었다.
- **결과**: 트레이 아이콘 색상이 사용률에 따라 바뀌고, 위젯을 접었다 펼 수 있고, 최근 24시간 사용 추이와 요일별 사용 패턴까지 확인할 수 있는 상태가 되었다.

#### 5. M6 — 설치 프로그램 제작 및 실제 설치/제거 테스트
- **AI의 반응**: 윈도우용 설치 프로그램(인스톨러)을 만들고, 실제로 설치·제거·재설치가 문제없이 되는지 직접 테스트했다.
- **결과**: 2.83MB짜리 설치 프로그램이 만들어졌고, 설치 후 실행/제거 후 흔적 삭제/재설치 후 설정 복원까지 전부 정상 확인되었다. 다만 메모리 사용량이 목표(150MB)보다 높은 177.3MB로 나와, 이 부분은 사용자 판단을 기다리는 상태로 남겨두었다.

#### 6. 반복해서 헤맨 문제 — 설정 창이 백지로 뜨는 버그
- **AI의 반응**: 설정 버튼을 눌렀을 때 창은 뜨는데 화면이 하얗게 비어 보이는 문제를 세 번에 걸쳐 다른 원인으로 마주쳤다.
  1. 처음에는 화면을 그리는 부분을 잘못된 스레드에서 실행해서 백지가 됐다.
  2. 고치는 과정에서 "창이 이미 열려 있는지 확인하는 부분"과 "창을 새로 만드는 부분"이 서로 다른 스레드에서 실행되면서 같은 창이 두 개 겹쳐 뜨는 문제가 생겼다. 하나를 닫아도 뒤에 똑같은 창이 남아있어 "안 닫힌다"처럼 보였다.
  3. 이걸 고치려고 "실패하면 반드시 알려주자"는 취지로 5초짜리 대기 로직을 넣었는데, 이게 하필 프로그램 전체를 담당하는 메인 스레드를 멈춰버려서 다시 백지 문제가 재발했다.
- **결과**: 최종적으로 "창 확인"과 "창 생성"을 한 곳에서 한 번에 처리하되, 그 결과를 기다리지 않고 넘어가도록 구조를 바꿔 해결했다. 이 과정에서 "오류를 확실히 표면화하려던 시도가 오히려 더 큰 문제를 만들 수 있다"는 점을 확인했다.

#### 7. 반복해서 헤맨 문제 — 설정 파일이 조용히 초기화되던 버그
- **AI의 반응**: 알림 임계값을 테스트하는데 4번 연속 다른 값(29%, 3%, 1%, 17%)이 나와 원인을 추적했다. 원인은 테스트에 쓴 메모장/파워셸이 설정 파일 맨 앞에 보이지 않는 특수 문자(BOM)를 붙였고, 앱이 이걸 읽지 못해 설정을 저장한 적이 없다는 듯 조용히 기본값으로 되돌리고 있었던 것이었다.
- **결과**: 이 특수 문자를 무시하도록 고치고, 설정 파일을 읽지 못했을 때 로그를 남기도록 추가했다. 메모장으로 설정 파일을 직접 고치는 사용자도 똑같이 색상·임계값·자동 시작 설정을 전부 잃을 뻔한 문제였다.

#### 8. 그 외 버그 — 알림 반복 발송, 차트 색상 오해, 게이지 회색 표시
- **AI의 반응**:
  - 알림이 60초마다 계속 다시 울리는 문제는, "리셋 시각이 바뀌었는지"로 판단하던 로직이 아주 미세한 시간 차이도 새로운 주기로 착각한 것이 원인이었다. 판단 기준을 "사용률이 갑자기 크게 떨어졌는지"로 바꿔 해결했다.
  - 사용자가 "황토색이 평균인가?"라고 질문한 것을 계기로, 차트 선 색이 게이지 경고 색과 같아서 주간 추이선이 항상 "주의 상태"처럼 보인다는 점을 발견하고 차트 전용 색상과 범례를 따로 만들었다.
  - 게이지가 가끔 회색으로 변하는 현상은 사용량 조회가 너무 자주 실패해서(HTTP 429) 생긴 것으로 확인되어, 실패 시 잠시 요청을 쉬어가도록 조정했다.
- **결과**: 세 가지 문제 모두 실제 사용 중 발견해 그 자리에서 수정했다.

#### 9. 공개 배포 검토 후 중단 결정
- **AI의 반응**: 인스톨러까지 완성된 시점에서 공개 배포 절차를 준비하다가, 사용자 판단에 따라 진행을 멈췄다. 코드에 남아있던 이메일 주소를 제거하는 등 공개 전 마지막 정리만 반영하고, 실제 공개(저장소 공개 전환, 릴리스 등록)는 하지 않기로 했다.
- **결과**: 저장소는 비공개(private)로 유지하고, 릴리스도 만들지 않았다. 다시 공개를 검토할 경우 필요한 절차는 `docs/tasks.md`에 정리해 두었다.

### 발생한 문제와 해결
- **문제**: 설정 창을 열면 화면이 하얗게 비어 보이거나, 창이 두 개 겹쳐 뜨거나, 프로그램 전체가 멈추는 현상이 세 차례에 걸쳐 다른 원인으로 발생했다.
- **해결**: 창을 확인하고 새로 만드는 처리를 한 곳(메인 처리 스레드)에서 순서대로 처리하되, 그 결과를 기다리지 않도록 구조를 바꿔 해결했다.
- **문제**: 알림 임계값을 몇 번을 바꿔도 적용되지 않고 매번 다른 값으로 보였다.
- **해결**: 설정 파일에 붙는 보이지 않는 특수 문자(BOM) 때문에 앱이 설정을 못 읽고 조용히 기본값으로 되돌아가고 있었던 것을 확인, 이를 무시하도록 수정하고 실패 시 기록을 남기게 했다.
- **문제**: 임계값 알림이 60초마다 반복해서 울렸다.
- **해결**: "리셋 시각이 바뀌었는지"가 아니라 "사용률이 갑자기 크게 떨어졌는지"로 판단 기준을 바꾸고, 최소 30분 간격을 두도록 했다.
- **문제**: 차트에서 주간 사용률 선이 항상 "주의 상태" 색으로 보여 혼란을 줬다.
- **해결**: 차트 전용 색상을 게이지 경고 색과 분리하고 범례를 추가했다.
- **문제**: 사용률 게이지가 가끔 회색(값을 못 믿는 상태)으로 바뀌었다.
- **해결**: 원인이 사용량 조회 서버의 요청 제한(HTTP 429)임을 확인하고, 이런 응답을 받으면 5분간 요청을 쉬어가도록 했다.

### 주요 결정사항
- 사용량 조회 API 검증이 성공해(M1 Go/No-Go) 본격 개발을 진행하기로 했다
- 기술스택을 Tauri 2.11 + Svelte 5.56 + Vite 8 + SQLite + uPlot으로 확정했다
- 다크/라이트/시스템 테마는 "색상 프리셋 교체" 방식으로 구현하기로 했다 (설정에서 손본 색은 테마 변경 시 초기화됨을 안내)
- 자동 업데이트 기능은 보류하기로 했다
- **공개 배포는 하지 않고 개인용으로만 유지하기로 했다** — 저장소는 비공개 유지, 릴리스 미등록
- 메모리 사용량 목표(150MB) 미달성(실측 177.3MB) 건은 목표를 현실에 맞게 조정할지, 화면을 다른 방식으로 다시 만들지 사용자 판단을 기다리기로 했다
